## 1. 先量出一个真 bug：两栏在这个宿主里**根本放不下**

重做前先测了几何，发现上一路的「左栏 + 右栏」布局**在可视区里只看得见左栏**：

| 量到的事实 | 值 |
|---|---|
| DSH 设置弹窗的**内容宽度** | **527px**（实测，不是 CSS 猜的） |
| 左栏声明 | `flex: 0 0 188px` |
| 右栏声明 | `flex: 1 1 440px` |
| 三者相加 | `188 + 20(gap) + 440 = 648 > 527` |
| ⇒ `flexWrap: wrap` 的后果 | 右栏被推到**新的一行**，`y=1015`，而视口高 `1102` |
| 用户看到的现象 | **右栏一片空白**（内容在 DOM 里、在视口外） |

第一次尝试（改 `nowrap` + 收缩）后右栏并排了，但只剩 **343px**；
把右栏声明 `minWidth: 420` 后直接**溢出容器 59px** —— 因为弹窗宽度是**固定的**，不会随内容变宽。

**结论：这个宿主里放不下两栏。** 于是改成**单列**，与「通用设置 / 模型 / 内置插件」那些原生页一致（一行一个字段）。

## 4. 顺手修掉一处**我自己写的不实措辞**

摘要行原来在 `active.models.length === 0` 时写「**未发现**」。实测陷阱：
`agy` 的概览 `models` 是 `[]`，而同一页的列表里明明有 **6 个**模型 ——
`/overview` 的 `models` 只是**缓存字段**，为空只意味着「还没预热」，**不等于**该 CLI 没有模型。

改为如实措辞：`尚未列出（概览未预热） · 列表命令：<命令原文>`，真正的发现结果留给「完整清单」。
**拿缓存状态冒充发现结果**，和把 DSH 的列表冒充外部 CLI 的列表是同一类错误。
